# Tengu Aurora

Vibrant, cinematic Minecraft shaders for **Iris**, written from scratch by **TenguTerror**.

Clear tropical water, warm sunsets, volumetric clouds, northern lights over snowy biomes,
a smoky Nether lit by its lava sea, and an End that is a dark void under a living nebula.

## Requirements

| | Tested with |
|---|---|
| Minecraft | Java 26.2 |
| Loader | Fabric 0.19.3 |
| Shader mod | Iris 1.11.1 + Sodium 0.9.0 |
| GPU | Any OpenGL 3.3 card; developed on an RTX 5080 |

Works with the vanilla textures and with Faithful 32x (the lava colouring is tuned for both).

## Install

1. Download `Tengu-Aurora-v2.0.0.zip` (do not unzip it).
2. Drop it into `.minecraft/shaderpacks`.
3. In game: **Options → Video Settings → Shader Packs**, pick **Tengu-Aurora-v2.0.0**, press **Done**.

Or build it yourself: `python build.py` writes the zip to `dist/`, and `python build.py --install`
also copies it into your shaderpacks folder.

## Features

- **Water**: refraction, depth absorption, sky and screen-space reflections, shore foam, caustics.
- **Sky**: physically-inspired gradient, warm sunrise/sunset band, sun and moon disks with moon phases, stars.
- **Volumetric clouds** that stay moonlit grey at night.
- **Aurora borealis** on clear nights in cold biomes (ice spikes, snowy plains, frozen peaks, …), drawn behind the clouds.
- **Volumetric fog and god rays**, soft blue light shafts underwater.
- **Rain**: grey, wind-slanted rain; wet darkened ground and reflective puddles that dry slowly afterwards.
- **Waving** grass, leaves, vines and crops.
- **Lava**: texture-driven blackbody colours (deep red → orange → yellow), gentle surface motion.
- **Nether**: drifting ash-smoke plumes lit orange from the lava below.
- **End**: swirling nebula, two star layers, and god rays from the void star.
- **Caves** stay properly dark; optional glowing ores.
- TAA, bloom, ACES tonemapping, sharpening and colour grading.

## Settings

Shader Pack Settings has Low / Medium / High / Ultra profiles (High is the default) plus these menus:

- **Lighting & Shadows**: shadow resolution and distance, sun/ambient/torch brightness, glowing ores.
- **Foliage & Weather**: plant sway, lava motion, rain puddles and puddle amount.
- **Sky, Clouds & Fog**: fog and god rays, clouds, aurora (brightness, or "Aurora In All Biomes"), Nether and End fog density.
- **Water**: wave height, caustics, reflections, shore foam.
- **Camera & Color**: TAA, sharpening, bloom, exposure, saturation, vibrance, contrast, vignette.

## Development

```
shaders/program/   one source file per pass (gbuffers, deferred, composite0-4, final)
shaders/lib/       shared code: settings, atmosphere, lighting, shadows, water, SSR
shaders/world*/    per-dimension stubs, generated by build.py
tools/validate.py  compiles every program on the local GPU to catch errors before Iris does
```

Run `python tools/validate.py` before every build. See [CHANGELOG.md](CHANGELOG.md) for history.
